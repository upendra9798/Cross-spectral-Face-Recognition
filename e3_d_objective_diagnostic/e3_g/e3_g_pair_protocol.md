# E3-G pair protocol

## Frozen representation

The audit uses the existing E3-D0 frozen regional artifacts and the original
E3 checkpoint (`Experiment_3_Uncertainty_best.pt`). The checkpoint is loaded
for a no-gradient extraction of normalized global RGB and thermal embeddings;
the backbone, Transformer Adapter, and regional extractor are not trained or
modified. Regional order is `left_eye`, `right_eye`, `nose`, `mouth`.

## Genuine pairs

Every existing dataset row is one genuine RGB-thermal pair:

```text
label = 1
rgb_index = i
thermal_index = i
subject_rgb = subject_thermal
```

This preserves the original sample pairing and gives one genuine pair per
dataset sample.

## Impostor pairs

For each RGB row, one thermal row is selected from the next subject in sorted
subject order, wrapping at the final subject. Within a subject group, rows are
cycled modulo the target subject's group size. The construction is
deterministic with seed 42 and is checked to ensure different subject IDs.
It produces one impostor for every genuine pair, so the baseline class ratio
is 1:1.

This is a reproducible baseline protocol, not an exhaustive all-pairs
evaluation. Pair observations share subjects and images, so confidence
intervals and generalization claims must use subject-level resampling or
subject-disjoint evaluation.

## Split isolation

Pairs are constructed independently within train, validation, and test. The
E3-D0 metadata verifies subject-disjoint and pair-disjoint original splits.
No pair crosses those split boundaries. Training is used only to fit
calibration parameters; validation is reserved for method/threshold
decisions; test is evaluated once after choices are frozen.

## Scores

For each pair, the audit records:

* global 512-D cosine similarity;
* four regional cosine similarities and distances;
* RGB and thermal subject IDs and pair keys;
* source row indices and the verification label.

The output is generated by `e3_g_baseline_audit.py`. `e3_g_pair_scores.csv`
is an audit artifact and must not be used to tune test thresholds.
